San Francisco airport airlines analysis dashboard

This Tableau workbook (AIRPORT_ANALYSIS.twb, built on Tableau 2026.2) analyzes flight route and traffic data for San Francisco International Airport (SFO). It combines tabular flight-log data with spatial geometry (route coordinates) to visualize route volume, traffic trends over time, gate/airline activity, and top-ranked routes.

Sample super store Dashboard

This project is an interactive Tableau dashboard created using the Sample Store US dataset. The purpose of this project is to analyze sales performance, profitability, customers, products, categories, and regional trends across the United States. The dashboard transforms raw sales data into meaningful visual insights that can help understand business performance and support data-driven decision-making.

Pandemic impact analysis

An interactive Tableau dashboard analyzing the COVID-19 pandemic across Indian states and union territories, covering confirmed cases, deaths, and recoveries with map-based and bar chart visualizations. This dashboard provides a state-wise breakdown of the COVID-19 pandemic in India. It combines geographic maps and comparative bar charts to highlight which states were most affected in terms of confirmed cases, deaths, and recoveries.
